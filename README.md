# SmartTrade (New-tread)

سامانه هوشمند تحلیل تکنیکال، سیگنال خرید و فروش و نمودار تریدینگ ویو.

Smart trading analysis system with technical analysis, buy/sell signals, and TradingView-style charts.

## Features

- Technical analysis tools
- Buy / Sell signal generation
- Interactive trading charts
- Powered by Gemini API (server-side)

## Tech Stack

- Kotlin
- Android (Gradle)
- Gemini API integration

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/pourianorozi/New-tread.git
cd New-tread
```

2. Open the project in Android Studio.

3. Copy `.env.example` (or configure secrets) and set your API keys.

4. Build and run on an emulator or device.

## Project Structure

- `app/` – Main Android application module
- `assets/` – Static assets
- `.github/` – GitHub Actions / workflows
- `workflows/` – CI related files
